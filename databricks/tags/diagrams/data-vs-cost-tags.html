Data tags and cost tags are two separate systems

A tag on a table never shows up in the bill. A tag on compute never controls who sees data.

Data tagsCost tags
What they labelCatalogs, schemas, tables, columns and volumes. Governed tags also label dashboards, notebooks, apps and Genie Agents.Compute and workloads: clusters, pools, SQL warehouses, jobs, and serverless workloads through usage policies.
Who sets themObject owners, or users with APPLY TAG. Governed tags also need ASSIGN.Whoever creates the compute or job. Workspace admins create serverless usage policies. Databricks sets the default tags.
Where you see themCatalog Explorer, the information_schema tag views and workspace search.The custom_tags column of system.billing.usage, budgets and Azure cost analysis.
What they are forFinding data, governing it, and driving access policies.Attributing cost and scoping budgets.
